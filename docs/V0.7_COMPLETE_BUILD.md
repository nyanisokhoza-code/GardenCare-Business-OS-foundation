# GardenCare v0.7 Smart Job Operations — Complete Build

Built on the existing Modern Nature GUI.

Included in this milestone:
- Reliable mobile drawer: phone Back closes menu first, outside tap closes, X closes, route selection closes.
- Existing customer records can be edited.
- Quotes can be edited (service, selling price, status, area).
- Smart Job now captures workers, labour hours, distance, return trip and calculates diesel from settings.
- m² drives recommended labour and material quantity; reserve bags remain configurable.
- Job detail workspace with before/during/after checklist, clean-up, variations and completion guard.
- Dedicated Call-outs workflow with configurable fee and copyable WhatsApp message.
- Important calculation/business controls are available in Owner/Developer Settings.
- Local-first; no API keys or Supabase credentials added.

Next integration layer can replace localStorage with authenticated database/storage APIs without changing the workflow model.
