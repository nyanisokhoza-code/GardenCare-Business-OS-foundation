# GardenCare Business OS v0.7 — Smart Job Operations

## Included
- Diesel travel calculation using job distance, fuel efficiency, diesel price and return-trip setting.
- Labour recommendation based on m² with manual override support at the GUI/business-rule layer.
- Material recommendation with wastage, rounding and reserve bags.
- Quote/job lifecycle foundation and job variation support.
- Before/during/after checklist and completion guard.
- Call-out fee and WhatsApp message generator.
- Activity timeline storage foundation.
- Important business controls kept in Settings so they can later migrate to a database.
- Mobile navigation reliability patch foundation.
- Local-first storage; no Supabase credentials or API keys added.
